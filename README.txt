Keep index.html and the assets folder together in the same folder.
Open index.html in Chrome, Safari or Edge. To share it, upload both to a web host (Netlify, GitHub Pages, your own site).
Music: assets/music.mp3 (Vaaroon) plays after the first tap on the envelope and keeps playing over the celebration videos (the videos are silent). To use your own song, replace that file with your own mp3 named music.mp3.
